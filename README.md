# 🛠️ RISC-V Assembly Projects

This repository contains a collection of **RISC-V assembly programs and exercises** developed as part of coursework and practice in computer architecture and low-level programming.  
The project's focus on understanding the **RISC-V ISA**, assembly programming, and the relationship between hardware and software.  

---

## 📚 Concepts & Skills Learned

- **RISC-V Instruction Set Architecture (ISA)**
  - Familiarity with **RV32I** base integer instruction set  
  - Load/store architecture and memory addressing modes  
  - Immediate, register, and control transfer instructions  

- **Assembly Programming Basics**
  - Writing and debugging assembly routines (`.s`, `.asm`)  
  - Using **labels, directives, and pseudo-instructions**  
  - Working with the RISC-V calling convention (register usage, stack frames)  

- **Control Flow & Logic**
  - Conditional branches and loops  
  - Function calls and returns using the stack (`jal`, `jr`, `ra`)  
  - Implementation of arithmetic and logical operations  

- **Memory & Data Handling**
  - Working with global/static data sections (`.data`, `.bss`, `.text`)  
  - Array indexing and pointer manipulation in assembly  
  - String and I/O handling through system calls (when supported by the simulator)  

- **Toolchain & Debugging**
  - Using **RARS**, **Spike**, or **Venus** simulators for execution and debugging  
  - Creating and running programs with assembler + linker scripts  
  - Reading disassembly (`objdump`) and debugging output  

- **Systems Thinking**
  - Understanding how high-level constructs (loops, conditionals, functions) translate into machine instructions  
  - Linking assembly with C code in mixed projects  
  - Building intuition for CPU datapath, control flow, and pipeline hazards  

---

## 🛠️ Tools & Environment

- **RARS (RISC-V Assembler and Runtime Simulator)** – simple IDE and simulator  
- **Venus** – browser-based RISC-V simulator  
- **Spike** – RISC-V ISA reference simulator  
- **GCC RISC-V Toolchain** – for compiling and linking assembly with C  
- **objdump / gdb** – disassembly and debugging
